# 一二布布私人桌宠

仅供一台 Mac 和一台 Windows 电脑使用的双人 2D 桌宠。Mac 固定显示“一二”，Windows 固定显示“布布”。

## 当前已经实现

- 透明、无边框、置顶桌宠窗口，支持拖动、点击反应和语义化闲时动作；每次动作会随机选择一张同类 GIF 并完整播放。
- 87 个 GIF 已统一为 `512 × 512` 透明画布，主体视觉尺寸一致；原图保留在忽略提交的 `source-assets/`。
- 默认桌宠尺寸为 `160 × 160`，可在设置中调整为 96～320px。
- 右键菜单只保留“看看TA在干嘛”和“设置”，并使用独立窗口保证最小尺寸下也能完整显示；设置窗口会贴着桌宠弹出。
- 首次运行时双方输入同一串至少 12 个字符的口令，软件通过 SPAKE2 安全交换并固定两台设备的签名公钥和机器特征；口令不会保存。
- 绑定后点击“看看TA在干嘛”即可通过安装包内置的腾讯 TRTC/IM 通道查看对方主屏幕，不需要 Tailscale、验证码或额外软件。
- 解绑只能从设置中发起，并且必须取得对方设备的数字签名同意；不提供强制解绑、恢复密钥或单机清除入口。
- 被查看端始终显示“桌面正在分享”，观看结束后自动消失。
- 首次运行自动启用开机启动；重复启动时只唤醒现有桌宠。
- 支持联网更新：程序使用 Tauri 签名更新并在用户确认后重启；GIF 和声明式动作规则可以运行中热更新，失败时自动保留或恢复上一版。

## 动作规则

动作按明确优先级运行，不再把所有素材放进同一个随机池：

1. 点击、拖动和查看对方桌面属于直接操作，会临时打断当前动作，并完整播放对应 GIF。
2. 系统持续播放音频时保持 `dance`；直接操作结束后，如果音频仍在播放，会立刻恢复 `dance`。
3. 对方正在查看本机桌面且当前没有音乐时使用 `shared`（缺少该素材时回退为 `idle`）。
4. 系统连续 10 分钟没有键鼠输入时持续使用 `sleep`；重新输入时完整播放一次 `wake`。音乐播放期间仍以 `dance` 为准。
5. 自动移动前切换为 `walk`，以约 36px/秒连续移动 90～220px，移动结束才恢复闲置。
6. `drink` 每 45～75 分钟提醒一次，`eat` 每 2～3 小时提醒一次。
7. 其余时间只在 `idle`、`look`、`sit` 中选择，不会无缘无故出现 `dance`、`work`、`eat` 等动作。

### 动作接入审计

| 动作 | 触发条件 |
| --- | --- |
| `idle` / `look` / `sit` | 普通闲置时按权重选择 |
| `walk` | 自动缓慢移动窗口的全过程 |
| `click` | 单击桌宠 |
| `happy` | 350ms 内双击桌宠，或成功连接对方桌面 |
| `angry` | 4 秒内连续点击桌宠 5 次 |
| `drag` / `drop` | 拖动桌宠期间 / 拖动结束 |
| `watching` | 点击“看看TA在干嘛” |
| `message` | 对方刚开始查看本机桌面 |
| `shared` | 对方持续查看本机桌面 |
| `sad` | 连接对方桌面失败 |
| `dance` | 系统持续播放音频 |
| `work` | 连续约 18 秒检测到活跃键鼠输入，此后每 3～5 分钟低频出现一次 |
| `drink` / `eat` | 分别每 45～75 分钟、2～3 小时提醒 |
| `sleep` / `wake` | 系统无输入 10 分钟后持续睡眠；恢复输入时播放一次起床 |
| `low_battery` | 电量不高于 20% 且未充电 |
| `charging` | 正在充电且电量低于 50% |
| `hot` | Mac 报告严重热状态，或 Windows 连续约 30 秒 CPU 负载不低于 85% |

所有现有动作类型都已绑定触发条件，不再存在无语义随机动作。素材检查仍发现一二缺少 `drag` 和 `shared`，两边都缺少 `drop`：一二拖动时暂用 `click`、被查看时暂用 `watching`，拖动结束暂回到 `idle`；补入同名 GIF 后程序会自动使用，无需改代码。

## 免费一体化方案

- 应用：Tauri 2 + Rust + React + TypeScript，框架和当前依赖均采用可免费使用的开源许可。
- 双机网络：腾讯 TRTC Web SDK 负责实时媒体，腾讯 IM 负责在线信令，两个 SDK 都直接打入 Mac/Windows 安装包。
- 凭证服务：EdgeOne Makers 海外云函数 + Blob，仅保存两台设备的公钥白名单并签发短期 UserSig，不保存桌面画面。
- 捕获：XCap（Apache-2.0），Mac 使用系统屏幕录制能力，Windows 使用系统捕获能力。
- 传输：Rust/XCap 捕获的画面在本机内存中转为自定义视频轨并交给 TRTC；只有当前绑定设备签名的查看请求才会启动捕获。
- 首次绑定：SPAKE2 口令认证密钥交换。设备私钥由 macOS 钥匙串或 Windows 凭据安全存储保护，不进入源码、安装包或前端存储。

## 开发

需要 Node.js、pnpm、Rust，以及对应平台的 Tauri 系统依赖。

```bash
pnpm install
pnpm tauri dev
```

生成当前电脑的安装包：

```bash
pnpm tauri build
```

Mac 安装包必须在 Mac 构建，Windows 安装包必须在 Windows 构建。完整双机设置见 [部署与双机连接](docs/部署与双机连接.md)。素材处理方法和可复现命令见 [素材尺寸标准化说明](docs/素材尺寸标准化说明.md)。

正式联网发布所需的密钥、GitHub Actions 和素材包操作见 [联网热更新](docs/联网热更新.md)。未配置发布地址的本地构建会继续使用安装包内置素材，不影响离线使用。

## 项目约束

本版只面向一台 Mac 与一台 Windows。绝对双向解绑意味着一台设备永久损坏后，另一台设备无法单独解除旧绑定；项目不会绕过这一约束。
