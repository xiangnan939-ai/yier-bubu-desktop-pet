# 部署与双机连接

## 用户操作

1. Mac 安装 `.dmg`，Windows 安装 `.exe`，不需要额外安装 VPN、远控客户端或浏览器插件。
2. 首次打开时，Mac 生成 16 位配对码，Windows 输入同一配对码。双方验证成功后才显示桌宠。
3. Mac 首次被查看时会请求 macOS 屏幕录制权限；这是系统强制权限，应用不会绕过。
4. 以后右键桌宠点击“看看TA在干嘛”，直接打开对方主屏幕。

## 当前联网架构

- 首次配对和日常信令同时使用 EMQX 与 HiveMQ 两个公共 MQTT TLS/WSS 节点，任一节点可用即可建立连接。
- 屏幕画面通过 WebRTC 在两台电脑之间点对点传输，MQTT 节点不接触画面。
- 应用使用绑定 ID 的 SHA-256 摘要生成隐藏主题，并在 Rust 层对每条消息校验绑定 ID、角色、时效、nonce 和 Ed25519 设备签名。从 GitHub 下载的其他副本没有两台已绑定设备的私钥，无法伪造有效请求。
- 配对码仅用于 SPAKE2 握手，3 分钟内有效，不保存或上传明文。设备私钥保存在 macOS 钥匙串或 Windows 凭据存储中。

## 屏幕与解绑

- Rust 只捕获主显示器，缩放到最宽 1280px，以 10fps 输入 WebRTC；不捕获麦克风、摄像头或系统声音，不把画面写入磁盘。
- 解绑必须经请求、对方签名同意、请求方签名确认三步完成。没有单机强制解绑或管理员覆盖入口。

## 构建

```bash
pnpm install
pnpm build
pnpm tauri build
```

Mac 与 Windows 安装包需在各自系统上构建。程序与全部动作素材作为同一版本的安装包一起发布。
