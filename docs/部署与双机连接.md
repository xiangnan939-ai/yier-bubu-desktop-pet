# 部署与双机连接

## 1. 两台电脑安装 Tailscale

两台电脑登录同一个 Tailscale 网络。Personal 方案足够本项目两人、两台电脑长期使用，无需购买服务器。

记下两台电脑在 Tailscale 中的设备名，或 `100.x.x.x` 地址。建议在 Tailscale 管理页开启设备审批和密钥过期提醒，不要做公网端口转发。

## 2. 安装桌宠

- 在 Mac 上构建并安装 `.dmg`，程序会固定加载“一二”。
- 在 Windows 上构建并安装 `.msi` 或安装程序，程序会固定加载“布布”。
- 首次启动会自动加入系统开机启动。操作系统或安全软件仍可能显示一次确认，这是系统行为，程序不会绕过。

## 3. 完成首次屏幕权限

Mac 首次被查看时会出现“屏幕与系统音频录制”授权提示。授权后如果 macOS 要求重启应用，请退出再打开一次；系统不撤销权限、应用身份不变化时，之后无需每次确认。

Windows 通常不需要逐次弹出捕获授权；如果安全软件或企业策略拦截，需要在对应设置中允许本应用。

## 4. 在两端配对

右键桌宠，打开“连接设置”：

1. “对方主机”填写另一台电脑的 Tailscale 设备名或 `100.x.x.x` 地址。
2. 两端“配对密钥”填写完全相同的随机长字符串，建议至少 32 个随机字符。
3. 保存后右键桌宠，点击“看看TA在干嘛”。

无需对方逐次同意。有人正在观看时，被观看端桌宠右上角会一直显示“桌面正在分享”；关闭观看窗口后提示自动消失。

## 5. 当前画面方案的边界

- 仅传输主显示器画面，不传声音。
- 约每秒 5 帧，优先保证低开发成本和两台私人电脑上的可用性。
- 画面只在内存中处理，不录制、不保存、不上传数据库。
- 应用服务监听端口 `39821`，只有配对密钥正确时才开始捕获。
- 网络加密由 Tailscale/WireGuard 提供；应用的 WebSocket 不应脱离 Tailscale 暴露到公网。

后续若需要更高帧率，可保留现有界面和配对流程，只将 JPEG 帧流替换为 RASystem 类似的 H.264 硬件编码链路。

## 6. 构建命令

```bash
pnpm install
pnpm build
pnpm tauri build
```

Mac 与 Windows 安装包需要在各自系统上构建。正式长期安装前，应分别完成代码签名；未签名包仍可私人测试，但系统会显示开发者来源警告。
