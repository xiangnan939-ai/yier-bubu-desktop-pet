# 素材尺寸标准化说明

## 已完成处理

- 共处理 87 个 GIF：一二 35 个，布布 52 个。
- 所有输出统一为 `512 × 512` 透明画布。
- 主体目标视觉高度为 400 像素，最大宽度 472 像素，脚底基线距画布底部 32 像素。
- 缩放依据整段动画所有帧的透明区域并集，避免某一帧特效被裁切。
- 保留每帧时长、循环方式和整段动画总时长。
- 使用 Lanczos 缩放和 GIF 透明帧优化；连续完全相同的帧可能被合并，但播放时长不变。

逐文件结果位于 `docs/素材尺寸标准化报告.json`。人工抽样联系图已确认没有明显裁切；带长文字、椅子或宽道具的动作会为了完整保留画面而自然缩小。

## 原图与重新生成

未经缩放的备份位于：

```text
source-assets/original-gifs-20260823/一二/
source-assets/original-gifs-20260823/布布/
```

该目录已加入 `.gitignore`，避免同一批大文件重复进入版本库。需要改变统一尺寸时，先保留当前输出，再运行：

```bash
python3 scripts/normalize-character-gifs.py \
  source-assets/original-gifs-20260823 \
  --output-root assets/characters \
  --report docs/素材尺寸标准化报告.json
```

脚本要求 Pillow 和 ImageMagick。不要直接反复处理已经缩放的 GIF，应始终从 `source-assets/original-gifs-20260823/` 中的原图重新生成。
