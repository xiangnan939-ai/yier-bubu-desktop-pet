# 联网更新与发布

项目只保留一条更新通道：Tauri Updater 从 GitHub Release 下载经数字签名的 Mac/Windows 程序包。所有 GIF 和动画规则都打入程序包，不再单独发布素材包。

## 发布准备

GitHub Actions 需要：

| 类型 | 名称 | 用途 |
| --- | --- | --- |
| Secret | `TAURI_SIGNING_PRIVATE_KEY` | Tauri 更新私钥 |
| Secret | `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | 私钥密码 |
| Variable | `TAURI_SIGNING_PUBLIC_KEY` | 客户端验证公钥 |
| Secret | `MACOS_CODE_SIGN_CERTIFICATE` | Mac 代码签名证书 |
| Secret | `MACOS_CODE_SIGN_CERTIFICATE_PASSWORD` | 证书密码 |

生成 Tauri 更新密钥：

```bash
pnpm tauri signer generate -w tauri-update.key
```

私钥只做离线备份，不提交到 Git。

## 发布

同步修改 `package.json`、`src-tauri/Cargo.toml` 和 `src-tauri/tauri.conf.json` 的版本号，然后推送对应标签：

```bash
git tag app-v0.5.23
git push origin app-v0.5.23
```

`.github/workflows/release.yml` 会构建两端安装包、生成 `latest.json`，并在两端都成功后公开 Release。设置页的“检查更新”会比较版本；有新版时直接下载安装并显示进度条，完成后重启。

更新只走 GitHub Release，不依赖付费中转服务。
